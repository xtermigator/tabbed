## Description
Keep your browser organized with My Tab Hub Pro. Find open tabs, save favorite websites and return to your work with saved sessions.

- Smart Search searches tab titles, URLs, saved favorites and local browsing history.
- Workspaces organize sites into School, AI Tools, Research, Projects, Personal or your own categories.
- Switch to a tab, pin it, close it or save it as a favorite.
- Save up to 200 website URLs per session and reopen them in a new window.
- Rearrange dashboard cards and widgets.
- Open the companion side panel in supported Chrome and Edge versions.
- Turn history and rediscovery suggestions off in Settings.

No account, external AI service or cross-browser sync. Suggestions are ranked locally by recency, frequency and workspace relevance. Searches match titles and URLs, not full webpage contents. History searches cover up to 1,500 available records from the last 90 days. Browser history access is requested at installation; history is initially enabled. All extension data stays in the current browser profile. Restoring a large session opens many tabs and can use significant resources.

## Single purpose
Help users organize, find and return to browser tabs and saved websites using a local dashboard and side panel.

## Permissions justification
| Permission | Purpose |
| --- | --- |
| tabs | Read open tab titles/URLs for search, organization, favorites and sessions; switch, pin and close tabs. |
| history | Read recent local browsing records for Smart Search and rediscovery suggestions; controlled by the history setting. |
| storage | Persist local favorites, sessions, workspaces, URL assignments, layout and preferences. |
| sidePanel | Display the extension's companion interface beside the active webpage. |

No host permissions, content scripts, remote executable code, analytics or data transmission to developer servers. Unused tabGroups permission removed.
